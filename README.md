# הניווטיה — מדריך אינטראקטיבי לקריאת מפה וניווט

אתר לימוד אינטראקטיבי בעברית (RTL) לצוערים בעולם קריאת המפה והניווט. אתר סטטי (HTML/CSS/JS ללא תלויות), מיועד ל-GitHub Pages, עם מצב יום/לילה ורספונסיביות מלאה לנייד.

🌐 **אתר חי:** https://regaj.github.io/nivutia/

## מה יש באתר

1. **יסודות קריאת המפה** — מפה טופוגרפית, קנה מידה, מקרא וצבעים, מדידת מרחק.
2. **תבליט וקווי גובה** — הדמיה אינטראקטיבית של "הצפת" תבליט + הסבר על פסגה, אוכף, שלוחה, ערוץ, קו פרשת מים ומצוק.
3. **הצלבה: השטח בעין ← השטח במפה** — משחק התאמה בין צורת תבליט (מבט תלת־ממדי) לבין ייצוג קווי־הגובה שלה.
4. **מפה אינטראקטיבית של ארץ ישראל** — לחיצה על אזור מציגה אופי שטח, גובה, אתגר ניווטי ומאפייני מפה.
5. **דקירת נקודת-ציון (נ״צ)** — מתרגל אינטראקטיבי בשני מצבים (קרא/דקור) ברשת ישראל החדשה (ITM).
6. **מחשבון אזימוט** — מרחק, אזימוט רשת, אזימוט מגנטי ואזימוט חוזר בין שתי נ״צ.
7. **שלושת הצפונים** — תרשים והסבר על צפון אמיתי/רשת/מגנטי והסטייה המגנטית בישראל.
8. **איך בונים ציר ניווט** — רכיבי הציר (נ.ה, מ.ח, נ.ב, נ.ס), כללי בטיחות למיקום נקודות, וחישוב זמן/קצב — מבוסס **מנחה 011** של צה״ל. כולל העמקה: חמשת השיקולים עם "השאלה המנחה", מדריך זיהוי נת״בים על המפה, טבלת ניתוח נת״בים, ו**מעבדת הציר האולטימטיבי** — זיהוי 3 נת״בים על מפה ובחירה מנומקת בין 3 חלופות ציר.
9. **סיפור דרך** — תיאוריה (גס/עדין, קו מוביל, נקודת גבייה, קו עצירה, נקודת תקיפה, הטיה מכוונת, מניין צעדים) + תרגיל סידור משפטי סיפור דרך שמצייר את הציר על מפה טופוגרפית.
10. **סדנת תכנון ציר** — הנחת נקודות מסוגים שונים על לוח ובניית "כרטיס ניווט" מלא (אזימוט, מרחק, צעדים) + שלד סיפור דרך אוטומטי, עם הדפסה/PDF.
11. **המצפן שבכיס** — מצפן חי מהמגנטומטר של הטלפון: אזימוט מגנטי/רשת, שושנת מעלות מסתובבת, ו"נעילת אזימוט" עם חץ הכוונה (iOS/Android; דמו בדסקטופ).
12. **בוחן** — מבחן עצמי בן 12 שאלות (ציון מעבר 85, כמו מבחן הבטיחות במנחה 011) עם הסברים ומקורות.

13. **🎮 משחק הניווט — מהמפה אל השטח** (`game.html`) — משחק מסכם: מתחילים בנקודה אמיתית בארץ (תבור, מירון, כרמל, גוש עציון, מדבר יהודה, מכתש רמון) עם מפה טופוגרפית שנבנית מנתוני גובה אמיתיים (קווי גובה כל 10 מ׳, ערוצים, נקודות גובה, רשת ישראל החדשה). דוקרים נ״צ של היעד, מחשבים אזימוט ומרחק, מצפינים מפה, ו"הולכים" בשטח עם מבט תלת־ממדי, מצפן ומונה צמדי צעדים. בסוף דוקרים את המיקום ומקבלים ציון: מרחק מהיעד, דיוק הדקירה ויעילות הדרך לעומת ציר אידיאלי (A* לפי זמן הליכה). 3 רמות קושי.

בנוסף: כפתור ובאנר לעוזר **NotebookLM**, ומצב יום/לילה (🌙/☀️).

## מבנה

```
index.html       דף יחיד עם כל הסעיפים
css/style.css    עיצוב (מוטיב טופוגרפי-צבאי) + Dark mode + רספונסיבי
js/app.js        כל הלוגיקה האינטראקטיבית + נתוני המפה המוטמעים
assets/map_data.json   נתוני הצללית שנוצרו (לתיעוד)
game.html        משחק הניווט (js/game.js, css/game.css)
assets/game/     רשתות גובה (Int16, דצימטרים, 25 מ׳ ב-ITM) + regions.json (ערוצים ונקודות גובה)
tools/build_game_terrain.py   בניית נתוני הגזרות מאריחי Terrain Tiles (AWS Open Data)
```

## הרצה מקומית

## מקורות

התוכן אומת במספר מקורות המצוינים במלואם בסעיף "מקורות" באתר: ויקיפדיה (עברית/אנגלית), Navigo, לוינסקי-וינגייט, המרכז למיפוי ישראל, US Army FM 3-25.26, EPSG, ו**מנחה 011 של צה״ל** (הוראות בטיחות לניווטים, מרץ 2025) — הבסיס לפרק בניית ציר הניווט ולבוחן.
